# Security

Report a vulnerability in Evidence Desk privately, through GitHub:
[open a private security advisory](https://github.com/open-autonomy-org/evidence-desk/security/advisories/new).
Only the maintainers see it. Please do not open a public issue or pull request for a vulnerability.

Include what an attacker can do, the steps to reproduce it on a synthetic workspace (never your real evidence), and the
version or commit you tested. We reply in the advisory, and credit you in it unless you ask us not to.

Evidence Desk runs on your own machine and holds no customer data on any server of ours; what it sends anywhere (a
Compliance statement to an Open Autonomy project, a trust center you host) goes only where you point it. So reports are
about the software itself: the app, its commands, its collectors and what it writes into a workspace or sends out.
